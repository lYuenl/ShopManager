# 店家管理系統（本機版）

以 Python NiceGUI + SQLite 製作，可在店內電腦執行，再由同一個區域網路中的手機或其他電腦瀏覽器操作。

## 功能

- 營運儀表板：今日收入、支出、預估毛利、帳務結餘與最近 7 天趨勢。
- 日常記帳：新增、編輯、刪除收入／支出，支援日期時間、分類、付款方式與備註。
- 商品與成本：管理商品售價及每份預估成本；記錄銷售時選取商品，可估算該筆銷售毛利。
- 統計報表：最近 24 小時、7 天、30 天、本月、今年及自訂日期，查看營收、支出、帳務結餘和支出分類。
- 帳務明細：日期、類型、關鍵字查詢。
- Excel 匯出：帳務明細、每日彙總、每月彙總三個工作表。
- SQLite 資料庫備份。

## 需求

- Windows 10/11
- Python 3.10 以上版本（安裝時請勾選 Add Python to PATH）
- 首次啟動需要可連線到 Python 套件來源，以安裝必要套件。

## 啟動

1. 將整個資料夾放在店內電腦，例如 `D:\ShopManager`。
2. 雙擊 `run.bat`。
3. 首次啟動會建立 `.venv` 並安裝相依套件，之後會啟動網頁服務。
4. 店內電腦瀏覽 `http://127.0.0.1:8080`。
5. 手機連上相同的店內 Wi-Fi，進入「備份與設定」頁面，使用顯示的區域網路網址。

## 網路與防火牆

- 服務預設監聽 TCP 8080，供區域網路裝置連線。
- 請勿在路由器設定連接埠轉發。
- 如 Windows 防火牆阻擋連線，可由系統管理員 PowerShell 執行以下命令，僅允許 Windows「私人」網路設定檔：

```powershell
New-NetFirewallRule -DisplayName "店家管理系統 TCP 8080" -Direction Inbound -Protocol TCP -LocalPort 8080 -Action Allow -Profile Private
```

- 若店內 Wi-Fi 啟用了用戶端隔離，手機可能無法連到電腦，需由路由器設定允許區域網路裝置互通。
- 同一區域網路中的裝置可能開啟管理頁面，請使用可信任的店內 Wi-Fi。

## 資料位置

- 資料庫：`data\shop.sqlite3`
- Excel 匯出暫存：`exports\`
- 資料庫備份暫存：`backups\`

請勿直接刪除或編輯執行中的 SQLite 資料庫。建議定期由「備份與設定」下載資料庫備份，另存至不同磁碟或外接儲存裝置。

## 損益數字說明

- **帳務結餘**是選定期間內「已記錄收入－已記錄支出」，採簡易現金口徑，不等同正式會計淨利。
- **預估毛利**只計入已選取商品且有商品成本快照的銷售紀錄；未選商品的收入不會被自動推算成本。
- 目前原料進貨以支出方式記錄，尚未實作庫存盤點／原料耗用，因此不能把預估毛利與帳務結餘混為同一個會計指標。
